# Pybind Skill
## What Is the Pybind Layer?
The C++ layer that exposes PyTorch C++ objects (at::Tensor, etc.) to Python using pybind11.

## Key Questions

**Q: Where are pybind11 bindings defined?**
A: `torch/csrc/` — hand-written bindings.
Generated bindings: `torch/csrc/autograd/generated/` — DO NOT CITE as path:LINE.

**Q: How is `THPVariable` related to `torch.Tensor`?**
A: `THPVariable` is the C++ struct that pybind11 exposes as the Python `torch.Tensor` type. It holds an `at::Tensor`.
`torch/csrc/autograd/python_variable.h:LINE — "struct THPVariable"`

**Q: How do you expose a new C++ function to Python?**
A: Add a binding in `torch/csrc/autograd/python_torch_functions.cpp` (hand-written) or via torchgen for auto-generated wrappers.

**Q: What are the generated binding files?**
A: `python_torch_functions_2.cpp` and siblings in `torch/csrc/autograd/generated/`.
These are regenerated by `tools/autograd/gen_autograd.py`. Never edit them directly.

## Blast Radius
- `torch/csrc/autograd/python_variable.cpp` — Tier 1 (all tensor Python access)
- Generated files in `torch/csrc/autograd/generated/` — read-only
